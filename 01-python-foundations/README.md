# Phase 1: Python Foundations for Data Engineering

## 🎯 Goal
Learn the Python skills that data engineers use daily — file handling, data formats, 
error handling, and writing reusable code.

## 📚 Lessons

| # | File | What You'll Learn |
|---|------|-------------------|
| 1 | `01_file_io.py` | Reading/writing text files, file paths, context managers |
| 2 | `02_csv_json.py` | Working with CSV and JSON — the bread and butter of data |
| 3 | `03_error_handling.py` | Try/except, logging, graceful failures |
| 4 | `04_functions_classes.py` | Writing reusable, testable code |

## 🏃 How to Run

```bash
# Run each lesson file
python 01_file_io.py
python 02_csv_json.py
python 03_error_handling.py
python 04_functions_classes.py
```

## ✅ When You're Ready
- Complete the exercises in `exercises/README.md`
- Move on to **Phase 2: SQL Fundamentals**

## 🔑 Key Takeaways
- Always use `with open(...)` for file handling (context managers)
- CSV and JSON are the most common data exchange formats
- Good error handling prevents pipeline crashes at 3 AM
- Functions and classes make your code reusable and testable
